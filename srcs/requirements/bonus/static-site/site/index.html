Inception

A small production-shaped infrastructure, built from scratch with Docker: every service in its own container, every image written by hand, one TLS door in front of all of it.

Static showcase · HTML, CSS and vanilla JavaScript · no PHP

The stack

Design rules

  • One process per container. Each image ends in exec, so the real daemon is PID 1 and receives signals directly.
  • No ready-made images. Every Dockerfile starts from debian:bookworm — the penultimate stable Debian — and installs its service itself.
  • Secrets are files, not variables. Passwords are mounted at /run/secrets/; nothing sensitive is baked into a layer or printed by docker inspect.
  • One entry point. Only 443 is published, TLSv1.2 and TLSv1.3 only. The database is never reachable from the host.
  • State lives in named volumes under /home/mozahnou/data, so containers stay disposable.
